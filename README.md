# Wholesale Gold Calculator

A tool for quickly calculating wholesale gold prices. Enter the weight, purity,
and current gold rate to get accurate values without manual calculation.

## Features
- Calculate gold value from weight and rate per gram
- Support for different purities (24K, 22K, 18K, etc.)
- Pure gold weight conversion
- Making charges / wastage and margin calculation
- Final total price, ready for bulk or wholesale orders

## How to Use
1. Enter the gold weight (in grams)
2. Select or enter the purity
3. Enter today's gold rate
4. Add making charges or wastage, if any
5. Get the final price instantly
